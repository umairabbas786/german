# Langey Frontend

This is the frontend for the Langey application, built with [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), and [Vite](https://vitejs.dev/).

## Requirements

- Node.js (Latest LTS recommended)
- npm (comes with Node.js)

## Setup

1.  **Navigate to the frontend directory:**
    ```bash
    cd new_frontend
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

## Running the Development Server

Start the development server with HMR (Hot Module Replacement):

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (default Vite port).

## Building for Production

To build the application for production:

```bash
npm run build
```

Previews the production build:

```bash
npm run preview
```

## Linting

Lint the codebase:

```bash
npm run lint
```
